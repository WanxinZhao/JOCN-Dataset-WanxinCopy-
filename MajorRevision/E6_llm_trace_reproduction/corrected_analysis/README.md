# Corrected E6 analysis

Generated by `revision_experiments/audit_e6_corrected.py` from the two immutable
E6 archives at evidence commit `82914127b70acf3b220bc09a56a179cb7abd1252`.
Run the script from the repository root with Python 3.12 and matplotlib.
See `revision_documents/13_E6_demonstration_revision.md` for accounting,
interpretation and reviewer-response text.

- `audit_summary.json`: hashes, provenance, counts, timing scope and limitations.
- `corrected_unique_configurations.csv`: 6,144 second-round configurations used
  in all corrected numerical summaries (6,120 ok and 24 no_signal).
- `deterministic_expected_configurations.csv`: independently specified expected
  Cartesian product; expectations are not inferred from observed rows.
- `corrected_baseline_comparison.csv`: exact-set coverage and duplication.
- `repeated_configurations.csv`: 2,048 first-round keys repeated in round two.
- `enumeration_timings.csv`: 31 configuration-generation timings; not LLM trials.
- `new_run_call_summary.csv`: six original API attempts, copied from the archive.
- `power_summary_by_route_and_format.csv`: equally weighted configuration means
  of active-channel-average GSNR/OSNR in signal bandwidth; no_signal excluded.
- `usecase1_corrected.pdf/png`: manuscript result figure, with the original
  workflow in panel (a) and corrected E6 data in panels (b)--(d). In this
  manuscript checkout it is regenerated from the audited CSV by
  `MajorRevision/generate_manuscript_figures.py`.
- `corrected_power_metrics.pdf/png`: GSNR and OSNR by route and launch power.
- `analysis_requirements.txt`: local analysis environment, not simulator runtime.

No new API calls or simulations are performed. Historical E3/E4/E5 audits retain
their original datasets and meanings. Corrected results do not establish
independent physical validation, an unattended workflow, or Reflection convergence.

## Reproduce from the published evidence checkout

The exact analysis script is also included here as `audit_e6_corrected.py`.
Obtain `WanxinZhao/JOCN-DATASET-Code` at commit
`82914127b70acf3b220bc09a56a179cb7abd1252`, which contains the two E6 archives.
Copy this script to that checkout's `revision_experiments/audit_e6_corrected.py`,
then run it from the evidence checkout root with Python 3.12 and matplotlib.
Outputs are written inside that evidence checkout under
`revision_experiments/E6_llm_trace_reproduction/corrected_analysis/`.
The archives are hash-checked before analysis; no LLM calls or simulations run.
The manuscript repository supplies the script and derived artefacts, while the
cited code repository supplies the original input archives and simulator source.
