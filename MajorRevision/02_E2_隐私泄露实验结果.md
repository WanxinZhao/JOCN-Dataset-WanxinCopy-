# E2：多攻击器隐私泄露实验

## 实验设计

- 复用 E1 的时序训练/验证/测试划分，避免随机划分和全数据拟合泄漏。
- 以 dominant CPE 为主要隐私属性，以 dominant RAT 为诊断属性。
- 攻击器包括逻辑回归、随机森林、MLP 和直方图梯度提升；报告各表示下最强攻击器的 Macro-F1。
- 比较原始私有特征、V1、V2、V3（3D/8D、σ=0/0.01/0.05/0.10）、PCA3、随机投影及随机/多数类基线。

## CPE 隐私结果

数值越低表示观察到的泄露越少，但必须结合下游效用一起判断。

| 表示 | 最强攻击器 Macro-F1 |
|---|---:|
| Raw private features | 0.2757 |
| V1 | 0.2481 |
| V2 | 0.2469 |
| V3 8D, σ=0.05 | 0.2435 |
| V3 3D, σ=0 | 0.2447 |
| V3 3D, σ=0.01 | 0.2366 |
| V3 3D, σ=0.05 | 0.2382 |
| V3 3D, σ=0.10 | 0.2319 |
| PCA3 | **0.2174** |
| Random projection 3D | 0.2246 |
| Stratified random baseline | 0.2530 |
| Majority baseline | 0.1235 |

## 可用于论文的结论

V3 相比原始特征、V1 和 V2 有适度隐私改善；更高噪声总体降低 CPE 可恢复性。但 PCA3 和随机投影泄露更低，因此不能声称 V3 是“最佳隐私方案”。结合 E1，V3 的价值是相对 PCA3 保留更高任务效用，而非单独达到最低泄露。

RAT 中测试集 570 条记录有 559 条 Wi-Fi、11 条 LiFi、无 5G，类别严重失衡；约 98% 的准确率就是多数类水平，不能作为隐私保护证据。论文应把 RAT 结果降为诊断性结果，主报告采用 CPE 的 Macro-F1/Balanced Accuracy。

完整逐种子结果见 `E2_privacy/privacy_results_per_seed.csv`，汇总及权衡图见 `E2_privacy/`。
