# E1：无泄漏时序划分下的语义效用实验

## 实验设计

- 对 2,849 条无线记录按时间顺序作 60%/20%/20% 的训练、验证、测试划分，并在边界各清除 10 条记录。
- 标准化器、语义阈值、光网络风险阈值、编码器和分类器均只在训练集上拟合。
- 使用 10 个随机种子；主指标为 Macro-F1，同时保留 Accuracy、Balanced Accuracy、AUROC 和 AUPRC。
- 比较多数类、分层随机、仅光特征、仅无线语义、原始无线+光、V1/V2/V3+光、PCA3+光、无噪声 V3 和 8 维 V3。
- 光网络与无线采集时间不重叠，因此这里只能称为“构造的跨域互操作基准”，不能称为同时刻的端到端实测。

## 主要结果

| 方法 | 二分类 Macro-F1（均值±95% CI） | 四分类 Macro-F1（均值±95% CI） |
|---|---:|---:|
| Raw wireless + optical | 0.6329 ± 0.0044 | **0.4161 ± 0.0051** |
| V1 + optical | 0.6455 ± 0.0040 | 0.3823 ± 0.0033 |
| V2 + optical | 0.6374 ± 0.0044 | 0.3958 ± 0.0175 |
| V3 + optical（σ=0.05） | 0.6457 ± 0.0054 | 0.3955 ± 0.0185 |
| V3 + optical（无噪声） | **0.6473 ± 0.0042** | 0.4041 ± 0.0109 |
| V3 8D + optical | 0.6399 ± 0.0056 | 0.3994 ± 0.0163 |
| PCA3 + optical | 0.5872 ± 0.0081 | 0.3829 ± 0.0045 |
| Optical only | 0.5390 ± 0.0036 | 0.3285 ± 0.0177 |
| Majority | 0.4334 | 0.2167 |

测试集的四分类样本为 436/115/13/6，最后一类只有 6 条，因此四分类结果仅能作为探索性结果。

## 可用于论文的结论

V3 在二分类中优于原始特征与 V2，但与 V1 的区间高度重叠，不能宣称显著领先 V1。无噪声 V3 的均值略高于 σ=0.05，说明当前数据不支持“注入噪声提高效用”的说法。四分类中原始无线特征最好，说明强压缩语义表示存在信息损失。论文应将结论改为“紧凑语义表示保持了大部分任务效用，并提供一定隐私折中”。
